# محتوى حقيقي لمتجر GLOBAL COMPANY

المتجر **لا يعرض** منتجات أو أسعاراً إلا بعد اعتمادها في الملفات أدناه.  
لا تستخدم صوراً أو أسعاراً من الإنترنت أو من الذكاء الاصطناعي كمنتجات فعلية.

## 1. بيانات الشركة — `data/business.json`

| الحقل | مثال | مطلوب للعرض |
|--------|------|-------------|
| `nameAr` | الاسم بالعربية | نعم |
| `heroEyebrow` | سطر صغير فوق العنوان (اختياري) | اختياري |
| `heroTitle` | عنوان الهيرو — **عن الشركة** | نعم |
| `heroLead` | جملة داعمة عن الشركة | نعم (أو `tagline`) |
| `tagline` | يُستخدم إن لم يُملأ `heroLead` | موصى |
| `about` | فقرة تظهر تحت الهيرو (بدون مبالغة) | موصى |
| `phone` | 05xxxxxxxx | نعم (التذييل) |
| `whatsapp` | رقم واتساب | اختياري |
| `email` | البريد | اختياري |
| `city` / `address` | المدينة والعنوان | موصى |
| `serviceArea` | مناطق التوصيل | موصى |
| `workingHours` | أوقات العمل | اختياري |
| `heroImage` | `/assets/brand/hero.jpg` | بعد رفع الصورة |
| `logo` | `/assets/brand/logo.png` | عند توفر الشعار |
| `deliveryCharge` | رقم بالشيكل أو `null` | عند تحديد السياسة |

## 2. المنتجات (5) — `data/products.json`

لكل منتج في `products[]`:

| الحقل |说明 |
|--------|------|
| `verified` | **`true` فقط** بعد مراجعة البيانات — وإلا لا يُباع |
| `name` | الاسم كما تبيعونه |
| `shortDescription` | سطر واحد (حصان، kW، مقاس…) |
| `description` | وصف حقيقي بدون ادعاءات غير مثبتة |
| `price` | رقم بالشيكل |
| `unitLabel` | مثل: للقطعة، للكarton |
| `sku` | رمز المخزون عندكم |
| `image` | مسار صورة **حقيقية** تحت `public/assets/products/` |
| `imageAlt` | وصف الصورة لإمكانية الوصول |
| `available` | `true` / `false` |

**الصور:** ضع ملفات JPG/WebP في:

`public/assets/products/`

ثم اكتب المسار في `image`، مثل: `/assets/products/motor-5hp-real.jpg`

## 3. التحقق قبل التشغيل

```bash
node scripts/validate-catalog.js
```

يجب أن يظهر: `catalogComplete: true` و5 منتجات `verified`.

## 4. تشغيل المتجر

```powershell
cd "d:\projects\global company"
npm run dev
```

## 5. ما نحتاجه منك (انسخ واملأ)

أرسل في المحادثة أو عدّل الملفات مباشرة:

```
الشركة (عربي):
الهاتف:
واتساب:
المدينة / التوصيل:

المنتج 1: الاسم | حصان/kW | السعر ₪ | SKU | اسم ملف الصورة
المنتج 2: ...
المنتج 3: ...
المنتج 4: ...
المنتج 5: ...
```

بعد استلام البيانات والصور، يُحدَّث الكتalog ويُفعَّل الطلب بالدفع عند الاستلام.
