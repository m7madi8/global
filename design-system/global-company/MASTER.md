# GLOBAL COMPANY — Polar Light

## Direction

Brilliant white surfaces, cool gray structure, deep ink type, steel accent. No warm beige/cream.

## Palette

- Background `#FFFFFF`
- Text `#243044` / strong `#0B0F14`
- Surface `#F2F5FA` / elevated `#FFFFFF`
- Muted `#5C6A7E`
- Border `#E2E9F2`
- Accent `#2F5499` / focus `#3B6FD4`

## Geometry (no sharp corners)

- Hero imagery: ~32px
- Cards / carousel items: ~24px
- Buttons / inputs: ~16px
- Small controls: ~14px
- Pills: count badges only

## Typography

Readex Pro — calm hierarchy, no excessive uppercase.

## Signature hero

Compact full-bleed hero: `hero-company.jpg`, RTL scrim, logo + wordmark, eyebrow + headline from `business.json` only—no CTA in hero; catalog follows directly below.

## Products

Horizontal carousel only (~3.15 cards desktop, ~1.3 mobile). Native scroll + prev/next + keyboard.

## Arabic

RTL layout, `ar-IL` for ILS prices.

## Icons

Local SVG stroke set via `public/js/icons.js` — menu, cart, chevrons, qty, trash, COD. Min touch 44px (`--touch-min`).

## Mobile-first

Compact hero on phone (copy before image). Nav sheet with overlay + focus trap. Cart drawer full width on small screens. Checkout summary duplicated above form on mobile.
